The third live call proved that this change alone was **insufficient**. Its [completion API](https://docs.tokenfactory.nebius.com/api-reference/inference/create-chat-completion) offers a `reasoning_effort=none` control. Source change `8963578` therefore uses prompt-requested JSON without forced JSON mode and disables reasoning for NVIDIA Nemotron requests. This is a **hypothesis-driven compatibility fix, tested only with provider mocks**; the real endpoint has not yet accepted it. The full backend suite passed locally (231 tests, 88.80% coverage).
