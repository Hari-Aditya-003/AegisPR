The third live call proved that this change alone was **insufficient**. Nebius's [public model catalog](https://tokenfactory.nebius.com/api/public/models_info) does not label Nemotron 3.5 Lightning with `JSON mode`, while the previous gateway forced `response_format=json_object`. Its [completion API](https://docs.tokenfactory.nebius.com/api-reference/inference/create-chat-completion) offers a `reasoning_effort=none` control. Source change `8963578` therefore uses prompt-requested JSON without forced JSON mode and disables reasoning for NVIDIA Nemotron requests. The fourth live run validates that configuration for this one planning task; it does not establish general model quality.

### Fifth-run plan-shape diagnosis and local correction

The fifth run's two cached, already-paid plan responses were inspected **without making any new provider request**. Both had one hypothesis; the first had eight test objects and the correction had four, all pointing to the same hypothesis and file path. The model treated the requested input examples as separate test objects despite a one-file instruction. Those small snippets also omitted the changed function's import, so blindly truncating to the first test would not establish a runnable result. The strict validator correctly rejected both plans instead of implying that any test passed.

The subsequent prompt-only change explicitly requires one object in each JSON array, all input cases inside a single `test_code`, and imports for changed functions. A targeted red/green test simulates eight objects then a valid correction; the full local backend suite passed **234 tests at 88.76% coverage**. [All six CI jobs passed for `b793a24`](https://github.com/Hari-Aditya-003/AegisPR/actions/runs/40114511707). After tagging the prior backend image `aegispr-backend:pre-20261024-one-test-prompt`, only the changed backend file was synced and only that service rebuilt/recreated on Dell. Health stayed `ok`, the GPU worker reported `cuda`, and the app budget ledger remained at eleven calls and $0.004837 estimated lifetime use. This is mock-backed instruction improvement and a healthy deployment, **not a live-validated model-output fix**. The one newly approved paid run has been consumed. No automatic or additional paid replay is authorized by that approval.
